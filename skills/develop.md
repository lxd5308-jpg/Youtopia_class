# Develop

Skills to use when working on the app's implementation:

- React component development and state management
- Vite application structure and build tooling
- CSS and module CSS styling for responsive UI
- Firebase Firestore reads/writes and real-time listeners
- Role-based UI flows for teacher and student views
- Data modeling and update logic in `src/App.jsx`
- Login flow and auth integration in `src/pages/LoginPage.jsx`
- Layout, navigation and shell components in `src/components/AppShell.jsx`
- Adding or updating mock/sample data in `src/data/mockData.js`
