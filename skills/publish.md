# Publish

Skills for deploying and shipping the app:

- Building the Vite app with `npm run build`
- Reviewing production output in the latest 'dist' folder
- Confirming `vite.config.js` build settings and asset paths
- Validating `package.json` scripts and deployment commands
- Checking that static assets, routes, and public files deploy correctly
- Deploying to GitHub Pages or Cloudflare, as documented in `README.md`
- Performing final smoke tests after deployment
