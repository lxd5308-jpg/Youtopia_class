# Review & Modification

Skills to apply when reviewing or modifying the app:

- Code review for React and Vite project structure
- Refactoring UI components for clarity and reuse
- Checking role-specific behavior across teacher and student pages
- Ensuring consistency between `src/pages/teacher/*` and `src/pages/student/*`
- Validating styling in `src/index.css`, `src/components/AppShell.module.css`, and page-specific CSS
- Reviewing Firebase configuration in `src/config/firebase.js`
- Assessing impact of changes on existing user flows and data preservation
